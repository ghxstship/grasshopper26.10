# Organizational Structure by Hierarchy

## Overview

Complete organizational structure organized by:
1. **Department** - Top-level organizational unit
2. **Team** - Functional group within department
3. **Area/Field** - Specialized domain or discipline
4. **Level** - Position hierarchy (Entry → Executive)

## Position Levels

| Level | Description | Examples |
|-------|-------------|----------|
| **Executive** | C-suite and top leadership | CEO, CFO, CTO, President |
| **Director** | Department heads and senior leadership | Marketing Director, Production Director |
| **Manager** | Team leaders and supervisors | Project Manager, HR Manager |
| **Lead** | Team leads and coordinators | Lead Technician, Team Lead |
| **Senior** | Experienced professionals | Senior Engineer, Senior Designer |
| **Mid** | Intermediate professionals | Coordinator, Specialist |
| **Entry** | Entry-level positions | Assistant, Junior, Intern |

## Query Examples

### By Department
```typescript
const executivePositions = await prisma.catalogItem.findMany({
  where: {
    metadata: { path: ['departmentCode'], equals: '0000' }
  }
});
```

### By Team
```typescript
const audioTeam = await prisma.catalogItem.findMany({
  where: {
    metadata: { path: ['teamCode'], equals: '4300' }
  }
});
```

### By Area/Field
```typescript
const technicalPositions = await prisma.catalogItem.findMany({
  where: {
    metadata: { path: ['area'], equals: 'Technical' }
  }
});
```

### By Level
```typescript
const directors = await prisma.catalogItem.findMany({
  where: {
    metadata: { path: ['level'], equals: 'director' }
  }
});
```

### Combined Query
```typescript
// All senior-level technical positions in Production
const seniorTechProduction = await prisma.catalogItem.findMany({
  where: {
    AND: [
      { metadata: { path: ['departmentCode'], equals: '4000' } },
      { metadata: { path: ['level'], equals: 'senior' } },
      { metadata: { path: ['area'], string_contains: 'Technical' } }
    ]
  }
});
```
