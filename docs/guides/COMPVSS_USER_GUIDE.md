## Introduction

COMPVSS is a comprehensive platform designed for event production teams to manage advancing requests, coordinate teams, track expenses, and ensure smooth event operations.

### Who Uses COMPVSS

- **Production Managers**: Oversee entire production workflow
- **Department Heads**: Manage specific areas (Technical, Hospitality, etc.)
- **Crew Members**: Submit requests and track tasks
- **Vendors**: Coordinate deliveries and services
- **Approvers**: Review and approve requests

### Key Features

- **Advancing Requests**: Submit and track all production needs
- **Team Coordination**: Manage crew and assignments
- **QR Code Access**: Generate and scan access codes
- **Expense Management**: Track budgets and expenses
- **Real-time Updates**: Stay synchronized across teams
- **Mobile Access**: Manage on-site operations

## Advancing Requests

### What is Advancing?

Advancing is the process of coordinating all production requirements before and during an event. This includes technical needs, hospitality, transportation, accommodations, and more.

### Request Categories

1. **Technical**
   - Audio equipment
   - Lighting systems
   - Video/LED screens
   - Power distribution
   - Rigging requirements

2. **Hospitality**
   - Catering
   - Green rooms
   - Dressing rooms
   - Refreshments

3. **Transportation**
   - Vehicle rentals
   - Shuttle services
   - Parking arrangements
   - Load-in/load-out logistics

4. **Accommodation**
   - Hotel bookings
   - Room blocks
   - Check-in arrangements

5. **Security**
   - Personnel requirements
   - Access control
   - Crowd management
   - Emergency protocols

6. **Staffing**
   - Crew requirements
   - Volunteer coordination
   - Credential management

7. **Marketing**
   - Signage
   - Promotional materials
   - Media requirements

8. **Permits**
   - Licenses
   - Insurance
   - Regulatory compliance

### Submitting a Request

1. Click **New Request**
2. Select **Category**
3. Fill in details:
   - **Title**: Brief description
   - **Description**: Detailed requirements
   - **Priority**: Low, Medium, High, Urgent
   - **Event**: Associated event
   - **Due Date**: When needed
   - **Attachments**: Add relevant files

4. **Add Specifics**:
   - Quantities
   - Specifications
   - Setup times
   - Special requirements

5. **Select Approvers**: Choose who needs to approve
6. Click **Submit**

### Tracking Requests

**Request Status**:
- **Pending**: Awaiting approval
- **Approved**: Approved and in progress
- **Rejected**: Denied with reason
- **In Progress**: Being fulfilled
- **Completed**: Fulfilled and closed

**Notifications**:
- Status changes
- Comments added
- Approvals/rejections
- Due date reminders

### Approving Requests

If you're an approver:
1. Go to **Pending Approvals**
2. Review request details
3. Check budget and feasibility
4. **Approve** or **Reject** with comments
5. Request clarification if needed

## QR Code System

### QR Code Types

1. **Access Codes**
   - Backstage access
   - VIP areas
   - Restricted zones
   - Time-limited access

2. **Equipment Codes**
   - Equipment tracking
   - Check-out/check-in
   - Maintenance records

3. **Asset Codes**
   - Inventory management
   - Location tracking

### Generating QR Codes

1. Go to **QR Codes** → **Generate**
2. Select **Type**
3. Fill in details:
   - **Name**: Identifier
   - **Description**: Purpose
   - **Valid From/Until**: Time restrictions
   - **Max Scans**: Usage limit
   - **Zone**: Access area

4. Click **Generate**
5. **Download** or **Print** QR code

### Scanning QR Codes

1. Open **QR Scanner** in app
2. Point camera at QR code
3. View validation result:
   - ✅ **Valid**: Access granted
   - ❌ **Invalid**: Access denied with reason

4. See details:
   - Code holder information
   - Access permissions
   - Scan history
   - Remaining scans

### Managing QR Codes

- **View Active Codes**: See all active codes
- **Deactivate**: Revoke access
- **Extend Validity**: Update time limits
- **View Scan History**: Track usage

## Troubleshooting

### Common Issues

**Can't Submit Request**
- Check required fields
- Verify event selection
- Ensure proper permissions
- Try refreshing page

**QR Code Not Scanning**
- Ensure good lighting
- Clean camera lens
- Try manual code entry
- Check code validity

**Expense Not Approved**
- Review rejection reason
- Add missing information
- Resubmit with corrections

**Not Receiving Notifications**
- Check notification settings
- Verify email address
- Check spam folder
- Enable push notifications

## Frequently Asked Questions

**Q: How far in advance should I submit advancing requests?**  
A: Minimum 2 weeks before event, 4-6 weeks for complex requirements.

**Q: Can I modify a request after submission?**  
A: Yes, if not yet approved. Click Edit on the request.

**Q: What if my request is rejected?**  
A: Review the rejection reason, make necessary changes, and resubmit.

**Q: How do I get QR code access?**  
A: Your manager will generate and assign codes based on your role.

**Q: Can I submit expenses on behalf of others?**  
A: Only if you have manager permissions for your team.

**Q: What if I find a safety issue?**  
A: Report immediately as Critical issue and notify on-site supervisor.
