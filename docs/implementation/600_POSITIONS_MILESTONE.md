## Usage Examples

### Query All Positions
```typescript
const allPositions = await prisma.catalogItem.findMany({
  where: {
    metadata: { path: ['type'], equals: 'position' }
  },
  orderBy: { order: 'asc' }
});
// Returns: 600 positions
```

### Find by Department
```typescript
const techPositions = await prisma.catalogItem.findMany({
  where: {
    metadata: { path: ['departmentCode'], equals: '9000' }
  }
});
// Returns: 41 technology positions
```

### Find Certified Positions
```typescript
const certified = await prisma.catalogItem.findMany({
  where: {
    requiresCertification: true
  }
});
// Returns: ~70 positions requiring certifications
```

### Search by Level
```typescript
const executives = await prisma.catalogItem.findMany({
  where: {
    metadata: { path: ['level'], equals: 'executive' }
  }
});
// Returns: All C-suite and executive positions
```
